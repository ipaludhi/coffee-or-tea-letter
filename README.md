One letter: **A** for coffee. Coffee is the bolder answer — dark, bitter,
hot, a jolt you feel — more vivid and funnier than tea's gentle calm, and
the honest morning default. The program writes exactly one byte, `A`,
to `/output/entry.txt`: no word, no explanation, no punctuation, no newline.

## Run it

```sh
node main.ts
```
